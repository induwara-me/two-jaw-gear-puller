# Hand Operated Two-Jaw Gear Puller

A 3D CAD design and mechanical assembly of a hand operated two-jaw gear puller developed using SOLIDWORKS.

## Project Overview

This project involved the 3D modeling and assembly of a hand operated two-jaw gear puller. The assembly consists of multiple mechanical components including the cross beam, jaws, lead screw, handle and pivot pins.

The assembly was designed with functional mates to allow the jaws and lead screw to move according to the intended mechanism while maintaining appropriate movement limits and avoiding unwanted interference.
